Publish-API 鉴权Token获取
获取Access Token
功能说明

此接口用于从荣耀开发者服务平台获取账号级Access Token，用于对接应用分发业务相关接口。

接口约束

已在荣耀开发者服务平台注册成为开发者，并且在管理中心>开放能力>凭证下，已申请API密钥。

获取到的 Client_id、API密钥请妥善保存。

上传应用文件
功能说明

上传资源文件，使用 “获取应用文件上传路径” 接口获取的下载URL，上传资源文件。需要记录下上传的 objectId，用于“更新应用文件信息”。

已上传的文件只暂存在云端，需要调用“更新应用文件信息”接口绑定应用文件信息，并提交审核；在审核通过后才会体现在荣耀应用市场中。

接口约束

1.已在荣耀开发者服务平台上创建安卓应用，并已经更新过应用信息、资源信息或已经提交过应用审核；

2.已使用“根据包名查询APPID”接口，获知要查询的应用的APPID；

3.已使用“获取应用文件上传路径”接口，获知文件上传的URL或objectId；

4.文件大小、类型约束，详见“获取应用文件上传路径”接口参数说明。

JAVA调用示例

public void uploadFile() throws IOException {
    RestTemplate restTemplate = new RestTemplate();
    String url = "https://appmarket-openapi-drcn.cloud.honor.com/openapi/v1/publish/file-upload?appId=123456&objectId=1234567890";

    // 创建文件资源
    FileSystemResource fileResource = new FileSystemResource(new File("/temp/app-release.apk"));

    // 创建请求头
    HttpHeaders headers = new HttpHeaders();
    headers.setContentType(MediaType.MULTIPART_FORM_DATA);

    // 增加鉴权请求头，token获取方法见上文
    headers.add("Authorization", "Bearer " + getAccessToken());

    // 创建请求体
    MultiValueMap<String, Object> body = new LinkedMultiValueMap<>();
    body.add("file", fileResource);

    // 创建 HttpEntity
    HttpEntity<MultiValueMap<String, Object>> requestEntity = new HttpEntity<>(body, headers);
    // 发送请求
    ResponseEntity<String> response = restTemplate.exchange(url, HttpMethod.POST, requestEntity, String.class);
    // 处理响应结果
    System.out.println("Response: " + response.getBody());
}
通过URL上传文件
功能说明

此接口作为“获取应用文件上传路径”、“上传应用文件”的替代，可以通过本接口声明一组文件上传任务，并指定该文件在公网的下载路径，由荣耀开发者平台后台服务下载文件，并支持根据文件对象ID查询文件的上传状态。适用于较大文件的上传场景。

已上传成功的文件只暂存在云端，需要调用“更新应用文件信息”接口绑定应用文件信息，并提交审核；在审核通过后才会体现在荣耀应用市场中。

接口约束

1. 已在荣耀开发者平台上创建安卓应用

2. 已使用“根据包名查询APPID”接口，获知要查询的应用的APPID

3. 资源文件格式、大小要求详见请求参数说明

4. 待上传文件在公网的下载路径，需是HTTPS方式提供、无鉴权、直接通过GET请求可获取文件流的URL

5. 查询文件上传状态时请限制查询频率低于 3min/次，否则可能因为请求频繁被网关限流

Integer

order 从 0 开始，如 应用介绍截图 需要绑定3-5张图片，可以指定order 分别为 0、1、2、3、4

•        对于仅支持绑定一个文件的文件类型，order可以缺省或者指定为0

•        对于支持绑定n个文件的文件类型，若order未缺省，则order的值应当在[0, n)整数区间内（n >= 1）

查询分阶段发布状态
功能说明

直接通过APPID，查询当前应用正在分阶段发布的版本信息

接口约束

1、已在荣耀开发者平台上创建安卓应用，并已经更新过应用信息、资源信息或已经提交过应用审核

2、已使用“根据包名查询APPID”接口，获知要查询的应用的APPID

3、有正在分阶段发布或待分阶段发布的版本，否则返回为空

接口说明
接口协议	HTTPS GET
接口URL	https://appmarket-openapi-drcn.cloud.honor.com/openapi/v1/publish/get-phased-release-info?appId=${APPID}
数据格式	Content-Type: application/json

更新分阶段发布信息
功能说明

当应用处于分阶段发布中（包括待发布），可使用此接口调整发布比例、发布时间，取消分阶段发布版本或者提前全网发布。

接口约束

1、已在荣耀开发者平台上创建安卓应用，并已经更新过应用信息、资源信息或已经提交过应用审核

2、已使用“根据包名查询APPID”接口，获知要查询的应用的APPID

3、有正在分阶段发布或待分阶段发布的版本，否则有对应报错提示

接口说明
接口协议	HTTPS POST
接口URL	https://appmarket-openapi-drcn.cloud.honor.com/openapi/v1/publish/update-phased-release-info?appId=${APPID}
数据格式	Content-Type: application/json
请求参数

Header

参数名称	是否必选	参数类型	参数说明
Authorization	是	String	认证Token，格式为：“Bearer ${access_token}”access_token 获取详见：获取Access Token

Body

参数名称	是否必有	参数类型	参数说明
operationType	是	Integer	

3-暂停分阶段发布（发布中状态可操作暂停分阶段发布）

0-重启分阶段发布（已暂停状态可操作重启分阶段发布）

5-取消分阶段发布（待发布、发布中、已暂停状态可操作取消分阶段发布；取消后不可恢复，需重新提交版本审核）

4-提前全网发布（待发布、发布中、已暂停状态可操作提前全网发布；全网发布操作不可撤销）

1-更新分阶段发布计划（待发布、发布中、已暂停状态可操作更新分阶段发布计划）


phasedReleaseInfo	否	PhasedReleaseInfo	operationType = 1 时必有，否则为空

PhasedReleaseInfo

参数名称	是否必有	参数类型	参数说明
releasePercentage	是	String	当前发布的百分比，0.00 - 100.00更新时发布比例只能增大，不可减小
releaseStartDate	是	String	分阶段发布开始时间，已到原计划的开始时间后，开始时间将不可修改。仅待发布状态可修改开始时间北京时间：yyyy-MM-dd'T'HH:mm:ssZZ，例如“2024-01-01T01:01:01+0800”
releaseEndDate	是	String	分阶段发布结束时间，到达结束时间后会转为全网发布，与开始时间的差值不可超过30天北京时间：yyyy-MM-dd'T'HH:mm:ssZZ，例如“2024-01-01T01:01:01+0800”
releaseNote	是	String	分阶段发布说明，500字符以内
